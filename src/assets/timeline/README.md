# Timeline artwork

`timeline.png` is the static ImageGen source used by `/timeline`.
To activate your animation, export it as `timeline.gif` in this directory.
The bot prefers the GIF when present and otherwise uses the PNG.
Keep the file below Discord's attachment limit. No labels are baked into the artwork.
